# SiteWatch

Паук-звонарь для наших сайтов. Висит в трее у часов и каждые 30 секунд открывает каждый сайт. Если сайт не отвечает 3 раза подряд, присылает письмо, а через GSM-модем ещё SMS и звонок.

Весь код в одном файле `main.cs`, C# 5 / .NET Framework 4.x. Значок exe лежит в `app.ico`, значок окна — в коде строкой Base64. Версия для macOS — в ветке `mac`.

## Сборка

Собирается компилятором, который уже есть в Windows, SDK ставить не нужно:

```
build.cmd        (или: make)
```

Результат — `SiteWatch.exe`. GitHub Actions собирает его на каждый push в `master`: Actions → build → Artifacts.

Скачанный из Actions exe Windows помечает как «из интернета», и SmartScreen предупреждает при запуске. Пометку можно снять: «Свойства» → «Разблокировать» или `Unblock-File` в PowerShell. Exe, собранный у себя через `build.cmd`, запускается без предупреждения.

## Запуск

- Двойной клик по `SiteWatch.exe` открывает окно. Крестик прячет программу в трей, проверка продолжается. Выйти совсем — через меню значка.
- **«Настройки»**:
  - сайты, адреса почты и телефоны — по одному в строке;
  - почта-отправитель (Gmail) и её пароль приложения — 16 букв с myaccount.google.com/apppasswords; нужна двухэтапная аутентификация;
  - COM-порт модема — его подбирает кнопка «Найти модем»;
  - галочки «не засыпать» и «автозапуск»;
  - кнопки «Тестовое письмо», «Тестовое SMS», «Тестовый звонок», «Сбросить настройки».
- По умолчанию вписаны litewms.ru, lite-box.ru, scanmaster.tech, limaster.ru и support.litewms.ru. Письма уходят с brand.korolev@gmail.com.
- Настройки хранятся в `%AppData%\SiteWatch\config.txt`, там же журнал `sitewatch.log`. Пароль зашифрован средствами Windows (DPAPI).
- Письма уходят через `curl.exe`, который есть в Windows 10 и 11: встроенный в .NET `SmtpClient` на части компьютеров обрывает соединение с Gmail («Сервер нарушил протокол»). На старых Windows без `curl.exe` письма уходят через `SmtpClient`. Порт 587 — STARTTLS, 465 — сразу TLS.

## Как решает, что сайт упал

- Сайт работает, если отвечает кодом 200–399 или 401/403: просит войти — значит, жив.
- Сайт упал — 3 неудачи подряд.
- Когда сайт упал, приходит письмо, а через модем — SMS с причиной и звонок.
- Пока сайт лежит, раз в 5 минут повторяются письмо и звонок.
- Когда сайт поднялся, приходят письмо и SMS «снова работает».
- Если не открывается и ya.ru, значит, пропал интернет у самого компьютера. Тревогу по сайтам тогда не поднимаем. Если интернета нет 3 круга подряд, через модем уходит SMS о том, что сайты сейчас не проверяются; когда интернет вернётся — ещё одно.
- Домен не найден и сайт ни разу не открывался — это опечатка в адресе, тревоги не будет.
- Пока программа работает, компьютер не уходит в сон (`SetThreadExecutionState`, kernel32).

## GSM-модем: SMS и звонки

Модем работает через AT-команды по COM-порту. SMS уходят в PDU-режиме и кодировке UCS-2, поэтому кириллица доходит, а длинный текст приходит одним сообщением из нескольких частей. Звонок — `ATD номер;`, до 30 секунд гудков, потом `ATH`. Брать трубку не нужно: сам звонок и есть сигнал. Сбросили вызов — модем сразу переходит к следующему номеру. Модему не нужен интернет компьютера, он работает через сотовую сеть, поэтому SMS доходят, даже когда у компьютера пропала связь.

**Какой модем нужен:** USB-модем с COM-портом, AT-командами, голосом и SMS.

- **SIM800C USB** — простой и дешёвый, 2G (GSM). Виден как «USB-SERIAL CH340 (COMx)», нужен драйвер CH340. 2G в России планируют сохранить до середины 2030-х.
- **SIM7600E-H USB** — 4G с переходом на 2G/3G для звонков. Порт для AT-команд называется «SimTech HS-USB AT Port».

Не подойдут обычные 4G-модемы операторов (ZTE MF831, Huawei E3372 и подобные): они работают как сетевая карта, COM-порта и звонков у них нет.

SIM-карте нужен тариф с исходящими звонками и SMS: «модемные» тарифы часто только для интернета. PIN-код на SIM-карте лучше отключить. Модем на SIM800 подключайте прямо в порт компьютера, без USB-хаба: при передаче он кратко потребляет много тока.

Как подключить:

1. Вставьте SIM-карту и подключите модем.
2. Нажмите «Найти модем»: программа опросит COM-порты и выберет тот, где ответил модем.
3. Нажмите «Сохранить», потом «Тестовое SMS» и «Тестовый звонок».
