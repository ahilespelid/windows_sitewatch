# SiteWatch

Паук-звонарь для наших сайтов. Висит в трее у часов и раз в минуту открывает каждый сайт. Если сайт не отвечает 3 раза подряд, присылает письмо. Когда подключим GSM-модем, ещё и позвонит.

Один файл `main.cs`, C# 5 / .NET Framework 4.x. Иконка лежит в коде строкой Base64.

## Сборка

Собирается компилятором, который уже есть в Windows, SDK ставить не нужно:

```
build.cmd        (или: make)
```

Результат — `SiteWatch.exe`. GitHub Actions собирает его на каждый push: Actions → build → Artifacts.

## Запуск

- Двойной клик по `SiteWatch.exe` открывает окно. Крестик прячет программу в трей, проверка продолжается. Выход — из меню значка.
- **«Настройки»**:
  - сайты, адреса почты и телефоны вводятся по одному в строке;
  - почта-отправитель Яндекс и её пароль приложения;
  - COM-порт модема;
  - галочки «не засыпать» и «автозапуск».
- По умолчанию уже вписаны: litewms.ru, lite-box.ru, scanmaster.tech, limaster.ru, support.litewms.ru. Письма идут на brand.korolev@gmail.com, dvrh.76@gmail.com с admin@litewms.ru.
- Настройки хранятся в `%AppData%\SiteWatch\config.txt`, там же журнал `sitewatch.log`. Пароль зашифрован Windows (DPAPI).

## Как решает, что сайт упал

- Работает, если ответ 200–399 или 401/403 (сайт просит войти, значит жив).
- Упал — 3 неудачи подряд. Тогда приходит письмо, пока лежит — напоминание раз в час, когда поднимется — письмо «снова работает».
- Если не открывается и ya.ru, значит пропал интернет у этого компьютера, и тревогу не поднимаем.
- Домен не найден и ни разу не открывался — это опечатка в адресе, письма не будет.
- Пока программа работает, компьютер не уходит в сон (`SetThreadExecutionState`, kernel32).

## Модем (заготовка)

Звонок AT-командами по COM-порту: `ATD номер;`, через 30 секунд `ATH`. Брать трубку не нужно, сам звонок и есть сигнал. Звонит, только если указаны COM-порт и номера. На живом модеме ещё не проверялось. Модем нужен с поддержкой голосовых вызовов, например SIM800 или SIM7600.
