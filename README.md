# SiteWatch

Программа для Windows, которая следит за сайтами и сообщает, если какой-то упал: письмом на почту, а в будущем звонком через GSM-модем.

Подходит для любых сайтов и серверов, ничего не зашито в коде. Каждый, кто скачал программу, сам заводит свои сайты, адреса почты и номера, и они сохраняются у него.

## Как пользоваться

1. Скачайте `SiteWatch.exe` и положите в постоянную папку, например `C:\SiteWatch\`. Устанавливать ничего не нужно, .NET тоже не нужен.
2. Запустите двойным кликом. Откроется окно с четырьмя вкладками.
3. **Сайты** → «+ Добавить сайт». Выберите, что проверять:
   - **Сайт** — открыть страницу, адрес вида `https://site.ru/`. Можно указать слово, которое обязано быть на странице: тогда заглушка nginx или страница с ошибкой не сойдут за «работает».
   - **Порт** — сервис без сайта, например база или API: `1.2.3.4:5432`.
   - **Ping** — жив ли сам сервер: `1.2.3.4`.

   Кнопка «Проверить сейчас» в окне добавления сразу показывает результат.
4. **Почта**:
   - добавьте адреса, кому писать;
   - ниже укажите ящик, с которого отправлять: выберите Яндекс, Mail.ru или Gmail и введите логин и **пароль приложения**;
   - нажмите «Отправить тестовое письмо».
5. **Настройки** → включите «Запускать вместе с Windows». Там же есть кнопка «Создать ярлык на рабочем столе».
6. Закройте окно крестиком. Программа уйдёт в трей (значок у часов) и продолжит проверять. Двойной клик по программе или ярлыку снова откроет окно.

Всё сохраняется само, кнопки «Сохранить» нет.

## Что делает

- Проверяет все сайты по кругу, по умолчанию раз в минуту.
- Сайт считается упавшим после 3 неудач подряд. Это защита от ложных тревог.
- Письма:
  - когда сайт упал;
  - напоминание раз в час, пока лежит;
  - когда снова заработал.

  Если упало несколько сайтов сразу, приходит одно письмо.
- Если пропал интернет у самого компьютера, а не у сайтов, программа это понимает (контрольный адрес `ya.ru`) и тревогу не поднимает.
- Цвет значка у часов: зелёный — всё работает; жёлтый — есть сбои; красный — сайт лежит; фиолетовый — нет интернета; серый — пауза.
- Журнал проверок хранится 30 дней.

## Где хранятся настройки

У каждого пользователя Windows свои: `%AppData%\SiteWatch\config.json`.

Пароль почты зашифрован средствами Windows. Прочитать его можно только под этим пользователем на этом компьютере.

Чтобы перенести список сайтов, почт и номеров на другой компьютер: «Настройки» → «Выгрузить настройки…», там — «Загрузить настройки…». Пароль почты не выгружается.

## Звонки через модем (заготовка)

Вкладка «Звонки» уже есть:
- список номеров (имя и номер);
- выбор COM-порта модема;
- «Проверить модем» — без звонка показывает модель, SIM-карту, уровень сигнала и оператора;
- «Позвонить на выбранный» — тестовый звонок.

Когда сайт падает, программа звонит по списку. Брать трубку не нужно: сам звонок и есть сигнал. На «снова работает» программа не звонит.

На настоящем модеме это ещё не проверялось. Модем нужен с поддержкой **голосовых вызовов**, например SIM800 или SIM7600 с USB, и в Windows он должен быть виден как COM-порт. Обычные USB-модемы операторов часто прошиты «только интернет».

## Почта: настройки ящика-отправителя

| Почта | SMTP | Порт |
|---|---|---|
| Яндекс | smtp.yandex.ru | 587 |
| Mail.ru | smtp.mail.ru | 587 |
| Gmail | smtp.gmail.com | 587 |

Нужен пароль приложения, он создаётся в настройках безопасности ящика. Обычный пароль не подойдёт. Порт 465 не поддерживается.

## Компьютер, который всегда включён

- Отключите сон: Параметры → Система → Питание → «Никогда».
- Программа запускается при входе пользователя в Windows. Поэтому нужен автовход или пользователь, который не выходит из системы.

## Сборка

Каждый push в `main` собирает `SiteWatch.exe` в GitHub Actions: вкладка Actions → сборка → Artifacts. Тег `v*` (например `v0.2.0`) дополнительно создаёт релиз с exe.

Собрать у себя (нужен .NET 8 SDK):

```
dotnet publish src/SiteWatch/SiteWatch.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```
