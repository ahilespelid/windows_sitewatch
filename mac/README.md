# SiteWatch для macOS

Тот же паук-звонарь, что и Windows-версия, только для Мака. Живёт значком-кружком в строке меню и каждые 30 секунд открывает каждый сайт. Если сайт не отвечает 3 раза подряд, присылает письмо, а через GSM-модем ещё SMS и звонок. Пока сайт лежит, раз в 5 минут повторяет письмо и звонок, а когда поднимется — присылает письмо и SMS «снова работает».

Весь код в одном файле `main.swift` (AppKit + SwiftUI), значок — в `AppIcon.icns`. Нужна macOS 13 Ventura или новее; подходят и Apple Silicon, и Intel.

## Сборка

**В GitHub Actions.** Workflow `build-mac` собирает программу на каждый push в ветку `mac` и по кнопке Actions → build-mac → Run workflow. Готовый файл лежит в Artifacts → `SiteWatch-mac`. Архив двойной: в скачанном zip лежит `SiteWatch-mac.zip`, а уже в нём `SiteWatch.app`.

**На самом Маке.** Нужны Xcode или Command Line Tools (`xcode-select --install`):

```
bash mac/build.sh
```

Результат — `mac/SiteWatch.app`. Собранная на своём Маке программа запускается без предупреждений.

## Первый запуск

1. Перенесите `SiteWatch.app` в «Программы». Автозапуск запоминает путь к программе, поэтому из «Загрузок» её лучше не запускать.
2. Программа не подписана сертификатом Apple, поэтому скачанную копию macOS при первом запуске не откроет. Снимите с неё пометку «из интернета» одной командой в Терминале:

   ```
   xattr -dr com.apple.quarantine /Applications/SiteWatch.app
   ```

   Другой путь: попробовать открыть программу, нажать «Готово», затем «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».
3. Разрешите уведомления, когда macOS спросит.
4. Откройте вкладку «Настройки»:
   - вставьте пароль приложения Google (16 букв) — пробелы можно не убирать;
   - нажмите «Тестовое письмо», потом «Сохранить»;
   - поставьте галочку «Запускать при входе в систему», если нужно.
5. Красная кнопка закрывает только окно: значок остаётся в строке меню, проверка продолжается. Выйти совсем можно из меню значка → «Выход».

## GSM-модем: SMS и звонки

Модем подключается к последовательному порту `/dev/cu.*`, команды — те же AT-команды, что в Windows-версии:

- SMS уходят в PDU-режиме и кодировке UCS-2, поэтому кириллица доходит, а длинный текст приходит одним сообщением из нескольких частей;
- звонок — `ATD номер;`, до 30 секунд гудков, потом `ATH`. Брать трубку не нужно: сам звонок и есть сигнал;
- модему не нужен интернет компьютера, он работает через сотовую сеть. Если интернета нет 3 круга подряд, уходит SMS о том, что сайты сейчас не проверяются, а когда интернет вернётся — ещё одно.

**Какой модем нужен.** Для Мака проще всего **USB-модем на SIM800C** (2G). Он подключается через микросхему CH340. На macOS 11 и новее он обычно работает без отдельного драйвера и виден как `/dev/cu.usbserial-…`; если порта нет, установите драйвер CH34x с сайта производителя микросхемы (WCH). Модемам на SIM7600 на Маке нужен драйвер производителя, без него их AT-порт обычно не виден. Обычные 4G-модемы операторов (ZTE MF831, Huawei E3372 и подобные) не подойдут: у них нет ни COM-порта, ни звонков.

SIM-карте нужен тариф с исходящими звонками и SMS («модемные» тарифы часто только для интернета). PIN-код на SIM-карте лучше отключить.

Как подключить:

1. Вставьте SIM-карту и подключите модем.
2. В «Настройках» впишите телефоны и нажмите «Найти модем»: программа опросит порты и выберет тот, где ответил модем.
3. Нажмите «Сохранить», потом «Тестовое SMS» и «Тестовый звонок».

## Чем отличается от Windows-версии

| | Windows | macOS |
|---|---|---|
| Значок | в трее у часов | в строке меню |
| Настройки | `%AppData%\SiteWatch\config.txt` | `~/Library/Application Support/SiteWatch/config.txt` |
| Пароль почты | в config.txt, шифрование DPAPI | в «Связке ключей» (служба «SiteWatch») |
| Автозапуск | реестр, `HKCU\…\Run` | `~/Library/LaunchAgents/ru.litewms.sitewatch.plist` |
| Не засыпать | `SetThreadExecutionState` | IOKit, как `caffeinate -i` |
| Письма | `curl.exe` (запасной путь — `SmtpClient`) | системный `curl` |
| Модем | COM-порт (`COM5`) | последовательный порт (`/dev/cu.usbserial-…`) |

Формат `config.txt` тот же, только порт модема записан как `modem_port=` вместо `com_port=`.

## Что нужно знать

- После каждого обновления программы macOS может один раз спросить разрешение на доступ к паролю в «Связке ключей». Введите пароль от Мака и нажмите «Разрешить всегда». Так происходит, потому что у новой сборки другая подпись.
- «Не давать компьютеру засыпать» запрещает только сон по бездействию. Если закрыть крышку ноутбука или выбрать «Сон» в меню, Мак всё равно уснёт — и модем тоже не сможет ничего отправить.
- При включении автозапуска macOS может показать уведомление «Добавлены фоновые объекты». Это нормально.
- Журнал работы — `sitewatch.log` в той же папке, что и настройки. Кнопка «Журнал» открывает её в Finder.
